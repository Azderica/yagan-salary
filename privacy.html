시행일: 2026년 10월 10일 · 대상: "야간월급 업로더"(이하 "앱")

1. 앱이 하는 일

앱은 유튜브 채널 야간월급 운영자가 직접 만든 영상을 운영자 본인의 채널에 업로드하고 제목·설명·태그·썸네일·공개 예약 시각을 설정하는 데에만 쓰입니다. 운영자 외의 사용자에게 제공되지 않습니다.

2. 접근하는 Google 사용자 데이터

  • 요청 권한: https://www.googleapis.com/auth/youtube.upload (YouTube 동영상 업로드·관리)
  • 이 권한은 운영자 본인 채널에 영상을 올리고 그 영상의 정보를 설정하는 데에만 사용합니다.
  • 시청자, 구독자, 댓글 등 다른 사람의 데이터는 읽거나 수집하지 않습니다.

3. 저장과 보관

  • Google이 발급한 인증 토큰은 운영자 컴퓨터의 로컬 파일에만 저장되며, 외부 서버로 전송하지 않습니다.
  • 앱은 별도의 데이터베이스나 서버를 두지 않습니다.
  • 운영자는 언제든 Google 계정 권한 페이지에서 앱의 접근 권한을 취소할 수 있으며, 취소하면 저장된 토큰은 더 이상 쓸 수 없게 됩니다.

4. 제3자 제공·판매

Google 사용자 데이터를 제3자에게 판매·공유·전송하지 않으며, 광고 목적으로 사용하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함해 그 정책을 따릅니다.
